# 蛋糕配方

本目录按器具收录蛋糕配方。

## 电饭煲蛋糕（`电饭煲蛋糕/`）

- 用的锅：**米家电饭煲 N1 1.6L**，就用自带的「蛋糕键」
- 烤多久：烤制流程约 **1 小时**（备料和晾凉不算在内）
- 记住四件事：蛋白打到硬性发泡、打发一定要充分；时间宁短不长；倒扣晾凉减少回缩；中间湿软是正常的，放凉更好吃

| 食谱 | 验证状态 | 风味要点 |
|---|---|---|
| [原味戚风蛋糕](<电饭煲蛋糕/原味戚风蛋糕.md>) | ✅ 已验证（1/2 原料版本） | 基础款，第一次做建议选它 |
| [可可戚风蛋糕](<电饭煲蛋糕/可可戚风蛋糕.md>) | ✅ 已验证（1/2 原料版本） | 可可粉先用热牛奶化开；低粉少放点 |
| [抹茶戚风蛋糕](<电饭煲蛋糕/抹茶戚风蛋糕.md>) | ✅ 已验证（1/2 原料版本） | 低粉和抹茶粉一起过筛；别烤过头 |
| [奶酪戚风蛋糕](<电饭煲蛋糕/奶酪戚风蛋糕.md>) | ❗ 未验证 | 奶油奶酪搅到顺滑；油少放点 |

> ✅ 目前实测过的有原味、可可、抹茶（都是 1/2 原料）；❗奶酪还没做过。

### 通用流程

1. 蛋清蛋黄分开，装蛋清的盆要无油无水
2. 做蛋黄糊（看各自食谱）
3. 蛋白打到硬性发泡，大概 3 分钟（一定要打充分，不然蛋糕不够蓬松）
4. 先挖 1/3 蛋白糊跟蛋黄糊翻拌，再倒回去，从底下往上翻拌
5. 电饭煲预热 3 分钟 → 按蛋糕键烤约 1 小时 → 用牙签戳一下，没有面糊被带出来就是熟了，倒扣晾凉（减少回缩）

## 空气炸锅蛋糕（`空气炸锅蛋糕/`）

- 用的锅：**小米空气炸锅 3.5L（1500W）** + 6 寸模具
- 核心思路：盖锡纸低温慢烤，最后去锡纸高温上色
- 记住三件事：必须预热；锡纸拱着盖、别包死；蛋白打到干性发泡（直立短尖角）

| 食谱 | 验证状态 | 要点 |
|---|---|---|

| [可可戚风蛋糕](<空气炸锅蛋糕/可可戚风蛋糕.md>) | ❗ 未验证 | 可可粉加热水化开；糖多 5 克 |
